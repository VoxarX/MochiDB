# MochiDB

**An open-source anime database built for developers.**

MochiDB is a structured anime database designed to provide accessible anime metadata, episode information, artwork references, and opening/ending timestamps.

The project aims to make anime data easier to access, integrate, and build upon.

## Project Status

🚧 **Under Development**

The MochiDB API is currently under development. Its architecture, database structure, and API endpoints are being worked on.

Things may change as development progresses. Contributions and feedback are welcome.

## Planned Features

- Anime metadata and descriptions
- Anime artwork and image references
- Episode information
- Opening and ending timestamps
- REST API powered by FastAPI
- Self-hostable database and API
- Developer-friendly documentation

## Data Sources

MochiDB currently uses AniSkip for opening and ending timestamp data.

Additional metadata and artwork sources will be documented as the project develops.
